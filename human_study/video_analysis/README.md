# Baseline 녹화 영상 기반 실패 진단

Baseline 녹화 200개에서 고정 간격으로 선정한 30개 표본을 분석했다. **27개에서는 안정적으로 물체를 들어 올리는 단계에 도달하지 못했다.** 세부적으로 접근 실패 1개, 파지 단계 실패 19개, 접근과 파지의 경계를 영상만으로 구분하기 어려운 사례 7개였다. 시각적 완료는 2개였고, 나머지 1개는 물체를 운반한 뒤 박스 뒤쪽 가장자리에서 놓는 장면이 있으나 최종 위치가 가려져 배치 결과를 확정하지 않았다.

이는 표본 내부의 정성 진단이다. 30개 표본의 완료 비율을 전체 성공률로 보고하지 않는다. 공식 성공률은 별도로 기록된 100회 평가 로그에서 산출한다.

![Baseline 실패와 완료의 시각적 근거](baseline_visual_evidence.jpg)

그림의 모든 행은 **사람 시범 30개로 학습한 Baseline**이다. A는 물체 주변에서 움직인 뒤 빈손으로 이탈하는 사례, B는 물체를 안정적으로 잡지 못하고 밀어내는 사례, C는 들어 올리기·운반·박스 입구 안으로 놓기까지 관찰되는 사례다. 증강 전후의 영상 비교가 아니다.

## 표본 선정과 자료 출처

- 원본: `IsaacLab_RS/videos/human30_seed101_eval42/`, `human30_seed111_eval42/`의 각 100개 MP4.
- 선정 규칙: seed별 trial `[0, 7, 14, 21, 28, 35, 42, 50, 57, 64, 71, 78, 85, 92, 99]`를 사용했다. 전체 trial 구간에 걸친 체계적 표본이며 무작위 추출이 아니다. seed당 15개, 총 30개 파일을 검토했다.
- 집계 단위: 선택한 영상 파일 하나를 사례 하나로 계산한다. 대표 그림이나 확대 프레임에 같은 영상이 여러 번 제시되어도 중복 집계하지 않는다.
- 원본 파일 SHA-256 30개는 모두 다르다. 동일한 trial 번호여도 두 학습 seed의 영상이 동일한 파일이라는 뜻은 아니다.
- 원본 촬영 명령과 모델 출처는 [baseline_audit.json](../results/mimic500_20261028/baseline_audit.json)에 기록되어 있다. 촬영 실행은 `--video`를 사용했고, 공식 성공률 16/100·19/100을 집계한 기록 평가의 `run.json`에는 `video: false`가 명시되어 있다. **촬영과 기록 평가는 별도 실행이므로 trial 번호를 연결하지 않는다.**
- 이 Baseline 분석과 비교되는 사람 30개 + Mimic 500개 정책의 대응 녹화는 없다. 따라서 이 통제 실험에서 증강 후 접근·파지 실패가 얼마나 감소했는지는 평가하지 않는다. 사람 100개 + Mimic 1,000개 조건의 별도 200회 평가 기록은 [통합 결과](../results.md)에 제시한다.

각 영상에서 12개 균등 간격 프레임을 추출했다. 시작 프레임이 검은 trial이 있어 첫 표본은 frame 1을 사용했다. 1280×720 원본의 작업 영역 `(x=200, y=250, width=650, height=460)`을 잘라 손·장난감·박스를 확대했다. 빠른 접촉이나 물체 소실이 모호한 5개는 20개 추가 프레임을, 그중 2개는 원래 프레임 간격 또는 원래 해상도로 다시 검토했다. 모든 frame 번호, 시각, 해시와 자르기 범위는 manifest에 보존했다. 영상 길이만으로 성공 또는 실패를 판정하지 않았다.

## 단계 분류 기준과 결과

가장 먼저 작업 진행을 막은 단계로 분류하되 영상의 가림이나 원근 때문에 구분할 수 없는 경우는 별도 항목으로 남겼다. 여기서 파지 실패는 물체 부근까지 도달한 뒤 안정적인 들어 올리기로 이어지지 않는 **행동 단계 분류**다. 실제 그리퍼 명령, 접촉력, 3차원 정렬 오차가 기록된 실패 원인 측정값은 아니다.

| 분류 | 영상에서 적용한 기준 | seed 101 | seed 111 | 합계 |
|---|---|---:|---:|---:|
| 접근 | 물체로 하강·정렬하지 못한 채 이탈하며 물체가 남음 | 0 | 1 | 1 |
| 파지 | 손가락이 물체 주변에 도달했지만 물체가 밀리거나, 머무르거나, 손만 이탈함 | 10 | 9 | 19 |
| 접근/파지 경계 불명 | 안정적 들어 올리기는 없지만 정확한 접근 정렬과 물림 상태를 구분하기 어려움 | 3 | 4 | 7 |
| 운반 실패 | 안정적 들어 올리기 뒤 박스에 도달하기 전 물체를 잃음 | 0 | 0 | 0 |
| 배치 결과 불명 | 박스까지 운반 후 가장자리에서 놓으며 최종 물체 위치가 가려짐 | 1 | 0 | 1 |
| 시각적 완료 | 물체를 들어 올려 운반하고 열린 손 아래 박스 입구 안으로 놓음 | 1 | 1 | 2 |
| 합계 | | 15 | 15 | 30 |

운반 실패 0개는 **이 표본에서 발견하지 못했다**는 뜻이다. 전체 평가에 운반 실패가 없다는 주장이 아니다. 시각적 완료와 배치 결과 불명에는 공식 성공 판정 레이블이 없다.

## 원인 가설에 제공하는 근거와 한계

표본 진단이 직접 지지하는 것은 **접근·파지 과정이 주요 병목이라는 관찰**이다. 안정적인 획득에 실패한 뒤에도 빈손으로 다음 동작을 진행하거나, 물체를 밀어 초기 상태에서 벗어난 뒤 복구하지 못하는 장면이 반복된다. 이는 시범에서 충분히 다뤄지지 않은 손–물체 상대 상태에 정책이 노출될 때 정렬·파지 동작을 일반화하지 못한다는 가설과 양립한다. 해당 가설은 데이터의 상대 위치·자세 분포 분석과 함께 검토해야 한다.

영상만으로 “수집 방식에는 문제가 없다”거나 “상황 다양성 부족이 유일한 원인이다”라고 확정할 수 없다. 정지 구간의 비중, 단계 전환 시점, 행동 표현, 부분 관측, 접촉 물리도 같은 행동 양상을 만들 수 있다. 일관된 텔레옵 절차는 수집 원칙이며 모든 시범의 행동 품질을 정량적으로 보증하는 지표가 아니다. 또 증강 후 영상이 없어 단계별 실패 감소를 직접 확인하지 못했으므로, Mimic 실험의 성공률 개선과 실패 메커니즘의 설명을 구분한다.

## 분석 산출물과 재현

- [annotations.csv](annotations.csv): 30개 표본의 분류·관찰 문장·원본 해시·근거 그림.
- [annotations.json](annotations.json): 표본 집계, 분류 신뢰도, 안정적 들어 올리기 관찰 여부와 개별 근거.
- [source_manifest.json](source_manifest.json): 선정 규칙, 원본 경로·해시, 12개 기본 프레임의 정확한 인덱스/시각.
- [detail_manifest.json](detail_manifest.json): 모호한 구간의 추가 프레임과 추출 이유.
- [illustration_manifest.json](illustration_manifest.json): 대표 그림과 GIF의 원본·시간 범위·재생 속도.

기존 원본 영상이 있는 환경에서 저장소 루트 기준으로 실행한다. 아래 명령은 영상 후처리만 수행하며 시뮬레이터를 실행하지 않는다. Python 환경에는 OpenCV, NumPy, Pillow, imageio-ffmpeg가 필요하다.

```bash
python human_study/video_analysis/extract_evidence.py --video-root /path/to/IsaacLab_RS/videos
python human_study/video_analysis/extract_detail.py --video-root /path/to/IsaacLab_RS/videos
python human_study/video_analysis/make_illustrations.py --video-root /path/to/IsaacLab_RS/videos
```

분류 레이블은 추출 스크립트의 자동 판정 결과가 아니라 보존된 프레임을 직접 검토한 주석이다. 주석 검토 시 `source_manifest.json`의 동일 파일 해시와 frame 인덱스를 기준으로 비교한다.
