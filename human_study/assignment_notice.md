# 과제 조건과 제출 안내

## 연구 과제

환경: `Isaac-Place-Toy2Box-Agibot-Right-Arm-RmpFlow-v0`

> 사람 시범으로 학습한 BC 정책은 Toy2Box에서 왜 성공률이 저조한가? 원인 하나를 진단하고, 그 원인을 겨냥해 성공률을 높여라.

1. **Baseline 재현:** 강의 학습 설정으로 학습·평가하여 출발점 성공률을 확인한다.
2. **실패 진단:** 접근·파지·운반·배치 단계로 실패 사례를 분류한다.
3. **가설:** 진단된 원인 하나와 예상 결과를 제시한다.
4. **통제 실험:** 한 번에 한 요인만 바꾸고 나머지 조건은 동일하게 유지한다.
5. **판정:** 결과에 따라 가설을 지지하거나 기각한다. 기각된 가설도 보고한다.

개선 방법은 데이터, Mimic 증강, 관측·행동 표현, 정책 구조·학습 방법 등에서 선택할 수 있다. 연구 축의 예시는 8주차 강의자료를 따른다.

## 공통 조건과 이번 실험

| 항목 | 과제 조건 | 적용 |
|---|---|---|
| 환경·성공·종료 | 박스·장난감 위치 분포, 성공 판정, 종료 조건 변경 금지 | 강의 환경과 평가 코드 유지 |
| 사람 시범 | 키보드 직접 수집, 학습 사용 20~100개 | 최종 모델 100개; 통제 실험 30개 |
| Mimic | 학습 사용 성공 생성 시범 최대 1,000개 | 최종 모델 1,000개; 통제 실험 0개 / 500개 |
| 학습 seed | 학습 설정 JSON의 seed를 101, 111로 설정 | `train.seed`: 101, 111 |
| 자체 검증 | 평가 seed 42, 100 rollout, horizon 800 | 세 조건의 여섯 모델 모두 해당 설정 사용 |
| 보고 | 성공률 평균 ± 표준편차 | 조건별 학습 seed 2개의 평균 ± 표본 SD, ddof=1; 최종 모델 66.5 ± 2.12% |
| 학습량 | 상한 없음, 비교 조건끼리 동일 | 2,000 epoch, 100 update/epoch, batch 100 |
| 최종 평가 | 조교가 비공개 seed로 동일 조건 평가 | 자체 검증과 구분 |

원인 가설의 통제 실험은 **사람 30개 고정, Mimic 0개 / 500개** 비교다. **사람 100개 + Mimic 1,000개**는 사람 수와 증강 수를 함께 늘린 데이터 규모 비교이며, 두 요인의 개별 효과를 분리하지 않는다. 최종 제출 모델은 이 규모 조건의 seed 101·111 모델이다.

최종 학습 자료는 사람 100개와 Mimic 성공 1,000개를 합친 **1,100개**다. 자동 annotation을 통과한 93개는 Mimic 생성 소스이며, 학습에는 사람 원본 100개 전체를 포함한다. 최종 모델의 자체 검증은 **68/100, 65/100**이었다. 평가 seed·rollout 수·horizon은 모든 조건에서 같지만, 30개·30+500개 조건은 영상 없이 평가했고 100+1,000개 조건은 영상·상태 기록을 활성화했다. 이 실행 차이와 비교의 한계는 [연구 결과](results.md)에 명시한다.
