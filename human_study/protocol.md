# 연구 설계와 판정 기준

## 수집 규칙과 진단 대상

키보드 시범은 접근 → 정렬·그리퍼 회전 → 하강·파지 → 들어 올리기·운반 → 배치의 순서를 기준으로 수집했다. 원본 사람 시범 30개를 두 학습 조건에 동일하게 사용한다. 일관된 동작 순서는 시범 간 행동 편차를 줄이기 위한 수집 원칙이며, 다양한 상대 위치를 포괄하는 데이터 분포와는 구분한다.

Baseline의 학습 seed별 trial 0–4 영상을 고정해 총 10개를 진단 대상으로 삼았다. 실패 6개는 안정적으로 물체를 들어 올리기 전에 발생했다. 이 중 2개는 파지 실패, 4개는 접근·정렬과 파지의 경계를 확정하기 어려운 실패로 분류했다. 표본은 전체 200회 실패 비율을 추정하는 무작위 표본이 아니다.

## 원인 가설 H1

사람 시범 30개가 물체와 손의 상대 위치 변화를 충분히 포괄하지 못해, 정책이 접근·정렬·파지 구간에서 일반화에 실패한다. 물체 기준으로 변환한 Mimic 성공 시범을 추가하면 같은 학습량에서도 성공률이 높아질 것으로 예상한다.

동작 규칙을 적용한 수집 방식 자체를 변경하기에 앞서 상대 위치 다양성 부족을 우선 검증 대상으로 선정했다. 다만 수집 품질의 다른 요인을 직접 비교하지 않았으므로 이를 모두 배제한 진단으로 해석하지 않는다.

## 통제 조건

| 항목 | Baseline | Mimic 증강 |
|---|---|---|
| 사람 시범 | 30개 | 동일한 30개 |
| 성공 생성 시범 | 0개 | 500개 |
| 총 시범 | 30개 | 530개 |
| 학습 seed | 101, 111 | 동일 |
| 정책 | BC-RNN, LSTM 400×2, GMM 5 | 동일 |
| 학습량 | 2,000 epoch, epoch당 100 update, batch 100 | 동일 |
| 최적화 | Adam, learning rate 0.001 | 동일 |
| 시퀀스 길이 | 10 | 동일 |
| 관측·행동 | 강의 low-dim 관측 7종, 행동 7차원 | 동일 |
| 모델 선택 | 마지막 epoch 2000 | 동일 |
| 평가 | seed 42, 100 rollout, horizon 800 | 동일 |

바뀐 요인은 Mimic 성공 시범 추가 여부다. 환경은 `Isaac-Place-Toy2Box-Agibot-Right-Arm-RmpFlow-v0`이며 환경 분포·성공 함수·종료 처리를 변경하지 않는다. 네 기록 평가는 동일한 강의 `play.py`를 headless로 실행했다. 모델당 optimizer update는 200,000회로 맞췄지만 데이터셋 크기가 달라 시범당 반복 노출 횟수는 다르다.

## 증강과 데이터 선택

강의의 자동 annotation → Mimic 생성 → BC 학습 → 평가 절차를 적용한다. annotation을 통과한 28개를 증강 소스로 사용하되 학습 조건 양쪽에는 사람 원본 30개를 모두 유지한다. 성공 생성 시범만 숫자순으로 500개 선택해 원본 30개와 결합한다. 실패 생성 시범은 학습에 사용하지 않는다.

생성 seed 1, action noise 0.01 등 강의 설정을 유지했다. 병렬 환경 수는 초기화 비용을 줄이기 위해 100에서 8로 조정했다. 생성 환경은 `Isaac-Place-Toy2Box-Agibot-Right-Arm-RmpFlow-Rel-Mimic-v0`다. PDF의 Mimic 단독 학습 예시와 달리 사람 원본을 합쳐 데이터 추가 효과를 비교한다. 구현상 조정과 접촉 센서 메시지의 한계는 [연구 결과](results.md)에 기록했다.

## 판정 기준

성공률은 모델별 공식 성공 횟수 / 100으로 계산한다. 조건별 평균 ± 표본 표준편차는 두 학습 seed의 성공률에 대해 계산하며 `ddof=1`, `n=2`를 명시한다.

- 두 seed 모두 개선: 이번 검증에서 일관된 개선 예측을 지지한다.
- 평균은 증가하지만 한 seed가 같거나 감소: 제한적 지지로 판정한다.
- 평균 변화량이 0 이하: 예상한 개선을 지지하지 않는다. 해당 결과도 보고한다.

판정 기준은 개별 rollout의 동일 궤적이나 통계적 유의성을 가정하지 않는다. 성공률 증가만으로 상대 위치 다양성 부족이 유일한 원인이라고 단정하지 않으며, 비공개 최종 평가 성능도 추정하지 않는다. 실측 결과와 판정은 [results.md](results.md)에 제시한다.
