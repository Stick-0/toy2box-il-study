# 연구 설계와 판정 기준

사람 시범의 행동·상태 분포, Baseline 실패 영상, 증강 전후의 통제 실험을 종합해 원인 가설과 개선 효과를 검토한다. 사람 30개를 고정한 증강 추가 실험과 사람 100개·Mimic 1,000개의 데이터 규모 비교를 구분한다.

## 수집 규칙과 진단 대상

키보드 시범은 접근 → 정렬·그리퍼 회전 → 하강·파지 → 들어 올리기·운반 → 배치의 순서를 기준으로 수집했다. 원본 사람 시범 30개를 두 학습 조건에 동일하게 사용한다. 일관된 동작 순서는 시범 간 행동 편차를 줄이기 위한 수집 원칙이며, 다양한 상대 위치를 포괄하는 데이터 분포와는 구분한다.

Baseline 녹화 전체 구간에서 seed별 15개를 고정 간격으로 선택해 총 30개를 검토했다. 획득 이전 실패 27개, 시각적 완료 2개, 배치 결과 불명 1개를 관찰하여 접근·정렬·파지를 우선 문제 구간으로 다룬다. 단계별 기준과 사례는 [영상 분석](video_analysis/README.md)에 있다.

## 원인 가설 H1

사람 시범 30개로는 위치·방향 조합에 대한 학습 사례가 부족해, 접근·정렬·파지 구간의 일반화가 제한된다는 가설을 검토한다. 물체 기준으로 변환한 Mimic 성공 시범을 추가하면 같은 학습량에서도 성공률이 높아질 것으로 예상한다.

원본 수집 규칙을 유지하면서 증강을 추가한다. 개폐 순서의 일관성만으로 시범 품질을 보증하지 않고, 초기 위치·방향 분포와 동수 부분집합을 분석해 가설과 맞지 않는 근거도 함께 확인한다. 전체 점유 구간 수는 사람 30개가 동수 Mimic보다 적지 않았지만, 낮은 x 영역의 국소 공백은 확인되었다. 분석이 지지하는 설명은 제한된 표본 수에서 일부 위치와 위치·방향 조합의 밀도가 낮다는 것이다. [데이터 분석](analysis/data_diagnosis.md)

## 통제 조건

| 항목 | Baseline | Mimic 증강 |
|---|---|---|
| 사람 시범 | 30개 | 동일한 30개 |
| 성공 생성 시범 | 0개 | 500개 |
| 총 시범 | 30개 | 530개 |
| 학습 seed | 101, 111 | 동일 |
| 정책 | BC-RNN, LSTM 400×2, GMM 5 | 동일 |
| 학습량 | 2,000 epoch, epoch당 100 update, batch 100 | 동일 |
| 최적화 | Adam, learning rate 0.001 | 동일 |
| 시퀀스 길이 | 10 | 동일 |
| 관측·행동 | 강의 low-dim 관측 7종, 행동 7차원 | 동일 |
| 모델 선택 | 마지막 epoch 2000 | 동일 |
| 평가 | seed 42, 100 rollout, horizon 800 | 동일 |

바뀐 요인은 Mimic 성공 시범 추가 여부다. 환경은 `Isaac-Place-Toy2Box-Agibot-Right-Arm-RmpFlow-v0`이며 환경 분포·성공 함수·종료 처리를 변경하지 않는다. 네 기록 평가는 동일한 강의 `play.py`를 headless로 실행했다. 모델당 optimizer update는 200,000회로 맞췄지만 데이터셋 크기가 달라 시범당 반복 노출 횟수는 다르다.

## 증강과 데이터 선택

강의의 자동 annotation → Mimic 생성 → BC 학습 → 평가 절차를 적용한다. annotation을 통과한 28개를 증강 소스로 사용하되 학습 조건 양쪽에는 사람 원본 30개를 모두 유지한다. 성공 생성 시범만 숫자순으로 500개 선택해 원본 30개와 결합한다. 실패 생성 시범은 학습에 사용하지 않는다.

생성 seed 1, action noise 0.01 등 강의 설정을 유지했다. 병렬 환경 수는 초기화 비용을 줄이기 위해 100에서 8로 조정했다. 생성 환경은 `Isaac-Place-Toy2Box-Agibot-Right-Arm-RmpFlow-Rel-Mimic-v0`다. PDF의 Mimic 단독 학습 예시와 달리 사람 원본을 합쳐 데이터 추가 효과를 비교한다. 구현상 조정과 접촉 센서 메시지의 한계는 [연구 결과](results.md)에 기록했다.

## 데이터 규모 비교

기존 30개에 추가 키보드 시범 70개를 병합한 사람 100개와 Mimic 성공 시범 1,000개를 결합한다. 자동 annotation을 통과한 93개가 생성 소스로 사용되며, 학습 합본에는 사람 원본 100개가 모두 포함된다. 실패 생성 시범은 제외하여 총 1,100개를 학습한다. 학습 seed·정책·관측·행동·최적화·200,000 update·최종 epoch 선택·평가 seed 42/100 rollout/horizon 800은 같은 설정이다.

이 비교에서는 사람 수와 Mimic 수를 함께 변경한다. 사람 100개만 학습한 조건은 수행하지 않았으므로, 이를 한 요인 통제 실험이나 사람 100개에서의 순수 증강 효과로 해석하지 않는다. 30개·30+500개 조건의 평가는 영상 기록 없이 수행했고, 100+1,000개 조건은 영상과 상태·행동 기록을 활성화했다. 원본 환경·성공 판정·종료·정책 실행 로직을 유지했지만 기록 옵션 차이도 비교의 한계로 밝힌다.

## 판정 기준

성공률은 모델별 공식 성공 횟수 / 100으로 계산한다. 조건별 평균 ± 표본 표준편차는 두 학습 seed의 성공률에 대해 계산하며 `ddof=1`, `n=2`를 명시한다.

- 두 seed 모두 개선: 이번 검증에서 일관된 개선 예측을 지지한다.
- 평균은 증가하지만 한 seed가 같거나 감소: 제한적 지지로 판정한다.
- 평균 변화량이 0 이하: 예상한 개선을 지지하지 않는다. 해당 결과도 보고한다.

판정 기준은 개별 rollout의 동일 궤적이나 통계적 유의성을 가정하지 않는다. 성공률 증가만으로 상대 위치 다양성 부족이 유일한 원인이라고 단정하지 않으며, 비공개 최종 평가 성능도 추정하지 않는다. 실측 결과와 판정은 [results.md](results.md)에 제시한다.

## 분석 방법과 해석 범위

원본 HDF5의 행동·관측, 녹화 영상, 훈련 로그를 분석 자료로 사용한다. 시범당 초기 관측 한 개로 장난감 x/y/yaw 구간 점유를 계산하고, 같은 30개로 맞춘 Mimic 부분집합과 비교한다. 구간 수와 거리·각도 기준의 민감도를 함께 기록한다.

Baseline 실패 분석 영상은 성공률 평가와 별도 실행이므로 trial별 라벨을 연결하지 않는다. 30+500개 조건에는 대응하는 영상과 평가 상태 궤적이 없어 이 통제 실험의 단계별 실패 감소량이나 실패 상태의 학습 분포 이탈 정도는 계산하지 않는다. 증강 추가의 성능 효과와 상태 다양성이라는 원인 설명의 지지 수준을 구분한다.

100+1,000개 조건은 성공률을 집계한 실행에서 영상 200개와 상태·행동 기록 200개를 저장했다. 저장 상태에서 계산한 원본 성공 판정과 native 출력·JSONL·summary를 대조한다. 각 모델의 첫 시행 영상은 기록의 일관성을 보여 주는 예시로 제시하며, 이 두 사례를 전체 실패 단계 분포로 해석하지 않는다. 초기 상태 구간 점유 27/96·91/96과 Baseline 영상의 획득 이전 실패 27/30은 원래 분석한 30개·30+500개 자료의 수치이며 100+1,000개 조건에 적용하지 않는다.
